# Evaluation Designs

## Monitoring

Use when the deployment is already live or randomization is unavailable. Claims should be descriptive.

## A/B Test

Use when runs can be assigned to control and treatment configurations in the same measurement window. Record agent configuration IDs for both groups.

## Staged Rollout

Use when introduction happens across teams, cohorts, or time windows. Document concurrent changes and drift.

## Before/After

Use only when no stronger comparator is available. Document learning effects, workflow changes, and seasonality.

## Scenario Suite

Use to validate framework mechanics before enterprise access or to compare configurations on approved synthetic or benchmark-like tasks. Do not treat scenario-suite results as enterprise impact evidence.
